为什么做这个

想出门的时候，
不必先做完攻略。

搜索能找到很多地方，但临时决定出门时，我们更想快点知道：今天适合去哪儿？这些建议从哪儿来？

你给一个出发地，再说说自己的想法。gogogo 会整理几个方向，附上参考笔记。看中了就继续细化；不合适，就改改要求再找。

怎么用

从一个念头开始

不用把计划想完整。

01

说出想法

填出发地。有时间、同行的人或偏好，也可以顺手写下。

02

找找笔记

用两个不同角度的关键词搜索，合并重复结果。

03

看看方向

从有正文可读的笔记里整理至多三个方向，并附上来源。

04

再改一改

选一个方向继续细化，或者换个要求重新整理。

AGENT PIPELINE

一次发现，四个明确的职责。

检索规划、证据筛选、卡片生成与方向细化分别处理，编排层负责调用顺序和阶段记录。

↗01 / 检索规划

Planner

生成查询计划

根据地点和需求生成两个不同角度的搜索词，并校验去重与约束条件。

◉02 / 证据研究

Researcher

筛选有效证据

基于笔记正文识别相关方向；证据不足时保留缺口，不强行补满结果。

✳03 / 结果编辑

Curator

生成来源卡片

把研究结果整理成至多三张方向卡，每张卡关联可打开的来源笔记。

→04 / 方案细化

Direction Planner

校验轻行程步骤

只使用本次已保存的笔记，核对步骤与原文依据后再呈现。

AGENT ORCHESTRATION

编排与证据流

一次运行会保存查询计划、检索结果、笔记证据与生成结果，便于回看和评测。
