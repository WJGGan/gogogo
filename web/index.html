技术实现

搜索、生成和来源核验

页面由 Node.js 提供。Python 与 Playwright 在部署机器上读取小红书搜索页和笔记正文；模型通过兼容 Chat Completions 的接口生成方向卡和细化步骤。

运行记录保存在本地 SQLite。细化时只使用本次已保存的笔记，证据不足就说明缺口。部署者需自行配置模型 API 和小红书登录会话。
